# Repentance Plus: фактически используемый Lua API

Статический скан 53 Lua-файлов. Частоты — число вхождений, не runtime-профиль.

## Критические точки bridge

1. `RegisterMod`, `mod:AddCallback`/`RemoveCallback`, `Isaac.AddCallback` и все callbacks из списка ниже.
2. Конструкторы/типы `Vector`, `Sprite`, `RNG`, `EntityRef`, `KColor`, `Font`, `SFXManager`, `Game`.
3. `Isaac`-поиск/спавн/ресурсы, `Entity`/`Player`/`Pickup`/`Room`/`Level`/`Sprite` методы.
4. Полный bundled `CustomHealthAPI` и `DeadSeaScrolls` — это не опциональная мелочь, а большая часть кода.
